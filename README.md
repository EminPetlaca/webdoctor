# WebDoctor – přestavby webů

Portfolio pro přestavby firemních webů. Jeden statický soubor `index.html`, bez build kroku.

## Nasazení na Vercel
1. Na vercel.com → **Add New… → Project** → importujte tento repozitář.
2. Framework Preset: **Other**, Build Command a Output Directory nechte prázdné.
3. **Deploy**. Vlastní doménu přidáte v **Settings → Domains**.
